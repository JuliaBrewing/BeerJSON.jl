# BeerJSON 1.0.1 schemas

The JSON Schema files of [BeerJSON](https://github.com/beerjson/beerjson) 1.0.1, copied
unchanged from the folder `json/` of the tag `v1.0.1` of the beerjson/beerjson repository
(commit `d1acebfcc9bff15db36cb6390b132eb3c678a59e`). They are distributed under the MIT
License; see [LICENSE](LICENSE).

`gen/generate.jl` generates the Julia types in `src/generated/` from them.
