Reading a recipe

A BeerJSON document is read with readjson, given the root type BeerJSONParser (or RootType), or parsed from a string with fromjson. Here we read one of the sample documents of BeerJSON, a Kölsch recipe converted from BeerXML:

using BeerJSON

file = joinpath(pkgdir(BeerJSON), "test", "samples", "converted", "Kolsh.json")
doc = readjson(BeerJSONParser, file)
typeof(doc)
BeerJSONParser{Int64, Float64}

The content of the document is in the field beerjson, with the BeerJSON version and lists of recipes, styles, hop varieties, equipments, and so on:

doc.beerjson.version
2.06
recipe = only(doc.beerjson.recipes)
recipe.name, recipe.type
("Lloyd&#39;s Krispy Kolsch", RecipeTypeEnum("all grain"))

The fields of the types are those of the schema, with optional ones nothing when absent:

fieldnames(RecipeType)
(:name, :type, :author, :coauthor, :created, :batch_size, :efficiency, :style, :ingredients, :mash, :notes, :original_gravity, :final_gravity, :alcohol_by_volume, :ibu_estimate, :color_estimate, :beer_pH, :carbonation, :apparent_attenuation, :fermentation, :packaging, :boil, :taste, :calories_per_pint)

Enumerations are wrapper types, with the value in the field value:

recipe.type.value
"all grain"

Style and batch size

style = recipe.style
style.name, style.category, style.style_guide
("K&#246;lsch", "Light Hybrid Beer", "BJCP 2008")

Measurements have a unit, from the units of the schema, and a value:

recipe.batch_size
VolumeType(VolumeUnitType("l"), 19.0028767)
println(recipe.batch_size.value, " ", recipe.batch_size.unit)
19.0028767 l

Unknown properties

Properties that are not in the schema (where the schema allows them) are kept in the field _extra, so that nothing is lost when a document is read and written back:

recipe.ingredients.hop_additions[1]._extra
Dict{String, Any} with 1 entry:
  "use" => "boil"
