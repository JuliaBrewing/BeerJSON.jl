# BeerJSON 1.0.1 sample documents

These sample documents were copied from the folders `tests/generic`, `tests/real` and
`tests/converted` of the [beerjson/beerjson](https://github.com/beerjson/beerjson)
repository, at tag `v1.0.1` (as converted by the tests of
[JSONSchema2Types.jl](https://github.com/rmsrosa/JSONSchema2Types.jl)). They are
distributed under the MIT License; see [LICENSE](LICENSE).

The tests check that every document is valid, and is read and written back without changes.
